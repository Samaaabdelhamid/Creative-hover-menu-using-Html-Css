# Creative Hover Menu 🎨

A simple and creative navigation menu built using *HTML* and *CSS* only.  
This project demonstrates how to use CSS hover effects to create stylish and interactive menus.

---

## ✨ Features
- Pure HTML & CSS (no JavaScript).
- Smooth hover animations.
- Responsive and lightweight design.

---

## 🚀 How to Run
1. Download or clone the repository.
2. Open index.html in your browser.
3. Hover over the menu items to see the effect.
